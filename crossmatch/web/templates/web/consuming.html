Consuming matches

Published crossmatches are streamed over SCiMMA Hopskotch. You can subscribe to the live stream with the hop client, or query recent matches through the REST API.

Where matches are published

  • Broker: {% if service.hopskotch_broker_url %}{{ service.hopskotch_broker_url }}{% else %}not configured{% endif %}
  • Topic: {% if service.hopskotch_topic %}{{ service.hopskotch_topic }}{% else %}publishing topic not configured{% endif %}

Subscribe with the hop client

{% if service.hopskotch_broker_url and service.hopskotch_topic %}

Install the client (pip install hop-client), authenticate, then subscribe:

hop subscribe {{ service.hopskotch_broker_url }}/{{ service.hopskotch_topic }}

Or from Python:

from hop import stream

url = "{{ service.hopskotch_broker_url }}/{{ service.hopskotch_topic }}"
with stream.open(url, "r") as s:
    for message in s:
        print(message)
